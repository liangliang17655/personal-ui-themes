## 自定义整套色系

点击“自定义整套色系”，使用取色器或HEX输入选择2～3个颜色，调整0～360°渐变方向及浅/深底色。

1. 调整草稿：只更新编辑器里的渐变色条，不改变当前页面或预设。
2. 确定预览：应用到页面背景、按钮、图表和装饰，保留原有输入与勾选。
3. 保存到本机：满意后保存已确认的方案，下次在同一浏览器恢复。再次修改草稿后，需重新确定才能保存。

十个预设保留。恢复默认配色仅重置自定义草稿，确定和保存后才分别影响当前效果与保存方案。渐变保留所选颜色顺序；按钮等衍生颜色可能为可读性而调整。

保存使用浏览器localStorage，无需登录、后端或存储接口，不向服务器提交配色。只保留一套自定义方案；清除网站数据后会丢失，换浏览器/设备不会自动同步。浏览器禁止本地存储时会明确提示。

验证命令：`node --test`（仅本独立Demo的配色测试，不启动其他项目）。

## 风格实验室（TASK-005，本地试用）

新增入口 [style-lab.html](style-lab.html)，原 index.html 与 studio-preview.html 保留。3 个系列共 7 种风格，每种 2 个默认配色，经典 10 主题仍在原页面。风格下拉改变材质、组件与装饰动效；默认主题改变整套颜色。

使用：选风格 → 选默认配色 → 展开“调一套自己的主题” → 调整小样 → 确定预览 → 填名称并保存。取消预览可回到首次预览前的方案。最多保存 30 套自定义主题到当前浏览器，支持导出 / 导入主题 JSON；本机存储不跨设备，清除网站数据可能丢失，请导出备份。存储不可用时显示失败反馈。

动效包含悬浮、液滴形变、柔光漂移、叶影、按压、光环与雷达扫光。支持总开关及系统减少动态效果，隐藏页面暂停循环。液态玻璃为 CSS 视觉演绎，不是真实折射；静态参考图片未提供动画证据。
