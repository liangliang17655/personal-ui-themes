# 鼠尾草极简

视觉方向（公开版不附原始参考图）：暖白、平面山形、细描边、抽象花瓣；少装饰。

主题 ID：`sage-minimal`。主题变量见 `themes.json` 中同名条目；数值是实现起点，不是截图精确取色。

## 独立视觉身份
采用抽象花瓣与平面山形。从原图提取配色关系、层级与材质，不复制 TWEE 商标、手机外框或业务文案。普通列表/表单用实色背景；装饰集中在欢迎区、空状态或一个重点卡片。细线图标统一笔画，正文保持清晰。

## 组件适配
桌面采用现有侧栏和内容网格；主卡片留白 20–28px、模块间距 24–32px 为建议起点。数据密集页缩小空白但维持标题与分组。按钮、筛选项、选中导航、弹窗、表单、图表都读取语义变量，不为主题复制业务组件。至少核对普通内容面与主色按钮上的文字可读性。

## 区别与边界
只在装饰资产与强调区域表现该主题的材质，不以模糊或透明度降低正文辨识度。
主题不代表业务类型；冥想、订阅、账号等功能均不能从原图推导。

## 动效建议（非图片事实）
按钮颜色反馈 120–180ms；卡片进入可用 6px 位移加透明度、180–260ms；减少动态效果时取消位移与循环。自然主题可在装饰上使用极弱慢变光，但默认不持续运行；霓虹主题也不默认循环闪烁。切换主题不动画正文颜色，不重置业务状态。
