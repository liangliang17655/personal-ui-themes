# 主题实现契约

## 共用结构
组件结构与内容由产品决定，主题只决定视觉语义。CSS 使用 `--ui-bg/surface/surface-muted/text/text-secondary/accent/on-accent/border/focus/danger/on-danger/success/warning` 等令牌。圆角、阴影、字体角色、图表色、装饰资源也通过注册表映射。组件不写主题 ID 分支来复制业务界面；必要的装饰变体在独立装饰组件中封装。

主题注册表与 CSS 是参考实施起点，需适配项目现有变量；不用它覆盖整份样式表。fonts 使用系统中文字体，不新增远程字体请求。图表除了颜色还使用标签/形状，不能仅凭颜色表示错误、选中或类别。

## 切换与持久化
运行时根元素采用 `data-ui-theme="主题ID"`。所有主题共用字段与业务状态。只在授权实现主题切换时接入现有设置页/入口与项目已允许的偏好存储；不自动新增设置页、数据库迁移或 IPC。未知/已删除的主题 ID 回退到已注册默认值；初始化在首屏绘制前应用偏好以减少闪烁，尊重 CSP 与现有入口。

深浅模式不是主题 ID 的替代品。深林和日落参考内部存在不同明暗场景，当前提供沉浸背景/文字的建议配对，未覆盖全部交互状态；接入 `surface-immersive/on-immersive` 等完整语义并核对所有状态后才能宣传为完整模式。系统模式选项只在相应模式已实现时提供。切换主题不循环轮播、不重置组件或滚动位置、焦点、校验结果与未保存内容，不改变权限、不发出网络请求。

## 可读性与检验
检查普通文字对实际表面的对比度，建议达到 4.5:1，大字与必要界面边界 3:1；透明表面要按合成后背景重新计算，不能以原始令牌计算代替视觉检查。图表色、装饰渐变和阴影已给出变量；assetSlots 仅说明所需资产，不代表已附可发布插画。展示字体是实现建议，系统字体是否存在与中文排版需验证。强调/错误背景使用配对的 on-* 文本。对每个已实现主题验证正文、按钮、输入框、placeholder、焦点、禁用、tooltip、对话框、图表与选中导航。说明无法确认的源字体、精确颜色与资产权属。

静态截图无法证明交互、响应式或动画。状态与断点必须由真实软件验证。使用键盘可到达的切换控件，显示主题名称/选中状态，缩略图带文本名称。低性能设备降级装饰，减少动态效果设置下关闭位移、循环、视差；正常主题切换以即时颜色替换为默认。

## 新增风格
用户明确请求追加图片或更新本 Skill 时：重新列举其指定目录，只读检查新增图；通过 source-manifest.json 哈希判断重复（公开初始包为空，无原始截图）。实际看图后定义稳定新 ID、中文名、相对视觉特征、原图映射和状态。只有用户确认属于旧主题时才补充旧主题，不自动合并或更名。追加 source-manifest.json 条目（文件名、角色、哈希）、文档、themes.json、CSS 和目录索引，更新索引中的主题/图片计数，保留全部旧图与旧 ID；各主题覆盖相同语义键，计算主要文字组合的对比度。CSS与注册表保持一致，不把未经验证的素材/动画标为已完成。
