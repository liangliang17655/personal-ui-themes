# Personal UI Themes / 个人 UI 主题风格库

十种可切换的软件 UI 风格，以及一个无需构建、无需联网依赖的交互 Demo。

## 在线预览

https://liangliang17655.github.io/personal-ui-themes/

桌面左侧选择主题；手机顶部横向滑动主题列表。输入、勾选项在主题切换时保留；刷新会清空这些演示状态。预览保存按钮只展示反馈，不写入真实用户数据。

## 安装 Skill

向 Codex 提供以下地址并请求安装：

https://github.com/liangliang17655/personal-ui-themes/tree/main/skills/personal-ui-themes

也可下载仓库 ZIP，把 `skills/personal-ui-themes` 放入你的工具支持的个人技能目录。用户可以自选磁盘，安装后确认工具已发现它。

## 使用

> 使用 personal-ui-themes，为这个软件设计可切换主题，保留现有业务功能。

主题包括雾青水岸、植物鼠尾草、象牙香槟、鼠尾草极简、深林自然、冰蓝云雾、酒红暖沙、霓虹深海、翡翠鎏金、日落暮紫。

目录：`skills/personal-ui-themes/SKILL.md` 为入口，`references/` 为主题与接入规范，`assets/tokens.css` 为建议变量，根目录 `index.html` 为自包含演示。下载单个 Skill 后可按文档实施；在线 Demo 是可选校准参考，不是运行依赖。

## 范围与扩展

安装 Skill 不会自动给软件新增主题切换功能。配色、字体、装饰与动效需按项目权限实施并验证。通过追加稳定主题 ID、主题规范和同一套语义变量来扩展，保留旧主题。原始第三方参考截图未公开；Demo 装饰是原创的简化 SVG，不是原效果图的精细还原。
