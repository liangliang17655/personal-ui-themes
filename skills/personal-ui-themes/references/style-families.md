# 风格系列与应用规则

本轮在经典 10 主题之外，新增 3 系列、8 种风格，每种 2 个默认配色。风格决定材质、组件形态与动效，配色决定整套颜色；不要仅换主色来冒充风格变化。名称与实现为原创设计演绎，不声称 Apple / Tesla 官方实现或复制品牌资产。

## 选择与资源

用户指定某种风格时，只读取本文件对应小节，结合 [style-presets.js](../assets/style-presets.js) 对应条目。资源采用无依赖 JS 注册表，浏览器可直接引用，Node 可 require；每项含 id / family / name / title / description / motion / presets。原 [themes.json](themes.json) 的 10 个 ID 和令牌不变。

独立试用页在仓库根目录 style-lab.html；图形采用原创 CSS。网页采用原生 HTML/CSS/JS，不要求 React，不为风格接入改变业务技术栈。安装 Skill 不会自动给软件安装切换或保存功能，必须在获授权的项目中实现。

## 通透玻璃

### spatial / 空间悬浮
- 默认主题：spatial-1 都市烟灰；spatial-2 极夜冰蓝。
- 深色环境层、轻薄面板、细高光边缘、不同距离的圆环和柔光。内容面板保持平直可读，不让表单或正文跟随倾斜。
- 轻微浮动与鼠标光晕；鼠标响应仅事件触发，触屏不依赖悬停。

### liquid / 液态透光
- 默认主题：liquid-1 冰晶银蓝；liquid-2 极光淡紫。
- 胶囊控件、透明厚边、圆润光泽和流动高光。网页试用使用 CSS 模拟形变与高光，不是真实光学折射，也不宣称等同系统 Liquid Glass。
- 缓慢液滴形变、边缘高光转动；避免让正文、图标或点击区域形变。

### frost / 轻柔磨砂
- 默认主题：frost-1 云雾白蓝；frost-2 奶油鼠尾草。
- 乳白面板、少量模糊、薄边、柔和阴影，适合内容阅读。不能照搬参考图的低对比小字。
- 背景柔光缓慢呼吸、用户触发的面板显现。密集数据区使用稳定表面。

## 自然柔感

### natural / 自然拟物
- 默认主题：natural-1 暖沙香槟；natural-2 森林琥珀。
- 暖光、石色台阶、拱形空间与局部叶影；卡片是实际界面，不将整张展板当软件截图。
- 枝叶摆动、光影漂移与轻微悬浮；装饰不遮挡控件，不复制原植物/石材/人物照片。

### soft / 柔软拟态
- 默认主题：soft-1 香槟暖灰；soft-2 珍珠冷灰。
- 同色面板、内外阴影、圆润按钮。焦点、选中和禁用必须有明确文字或轮廓，不能仅依赖微弱阴影区分。
- 按下时凸起变凹陷，背景光环轻缓呼吸。正文和图表保持清晰。

### olive / 橄榄生活
- 默认主题：olive-1 橄榄暖橙；olive-2 奶油苔绿。
- 橄榄与暖橙、大圆角、弧形刻度、简洁控制面板。橙色只突出主要操作和状态，不铺满所有区域。
- 温度弧形进度、柔软波纹与开关反馈。温度/专注数据仅为演示，不能声称控制真实设备。

## 科技座舱

### cockpit / 金属座舱
- 默认主题：cockpit-1 石墨电蓝；cockpit-2 曜黑青绿。
- 深色金属面板、电光强调、大数字与清晰刻度。减少无意义发光，不模仿品牌 Logo、车辆模型或官方控制系统。
- 圆环雷达扫光、仪表描线、图表启动。持续动画只在小面积装饰中使用，切换不重置数据。

## 自定义与持久化

- 选择风格后，在对应风格内编辑草稿。保持两个默认配色不可变；自定义另存。
- 颜色 2～3 个，#RRGGBB；angle 0～360；mode light / dark。配色派生应同时覆盖背景、正文、按钮、图表及弹窗。
- 试用参数：glass 72～98（表面不透明度百分比，数值越低越通透）；blur 0～24px；round 12～36px。维持可读性，不允许任意 CSS 字符串导入。
- 编辑只更新小样；确定预览后才影响整页；取消回到首次预览前的方案；与已确认配置一致时才能保存。
- 浏览器 localStorage 最多 30 套；保存失败明确反馈，不能声称已保存。导出 JSON kind=personal-ui-theme / version=1 / name / config；导入前校验名称、风格 ID、所有参数范围及色值，失败保持当前方案。
- 浏览器数据不跨设备，也不是账号同步；导出文件可携带。不要把网站偏好存储规则硬套进桌面项目，按项目已有的配置存储方式适配。
- 关闭动效与 prefers-reduced-motion 均取消循环、过渡、入场和位移；后台页暂停装饰循环。正文、焦点与业务状态不依赖动画。

## 显示与切换过渡

新风格预览按用户要求采用淡入淡出：主题切换约 420ms 交叉淡化，保持颜色与文字配对，不逐个插值色值；编辑区约 320ms 淡化并平滑收放高度；弹窗约 280ms 渐入、240ms 渐出，关闭按钮、完成和 Escape 都应先淡出再关闭。连续操作以最后一次选择为准，过渡结束清理叠层；关闭动效或系统减少动态效果时立即完成到最终状态。不要为了过渡重建真实业务界面或清空输入。
